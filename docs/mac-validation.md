# Mac 验证记录（2026-10-31）

## 0.2.1：下载覆盖的签名句柄兼容修复

绑定模式下载覆盖曾返回“不允许的夸克任务或文件路径”。原因是工作程序把云端完整 FID 限制为简单字母数字 ID，误拒绝官方 SDK 返回的带 `|` 签名句柄，并非存档目录真的越界。

修复将 FID 作为有长度限制的完整不透明参数原样传入，不截取或解析签名；空值、控制字符、选项样式输入及越界输出路径仍拒绝，命令白名单与存档校验、覆盖前备份保持不变。

- 新增回归先复现拒绝，再验证下载、目录操作原样接收签名句柄。
- 合成存档经过同一 worker 校验后下载覆盖、保留本机偏好、创建覆盖前备份并恢复成功。
- 使用真实绑定 Agent 下载云端存档至隔离目录，129 个文件通过快照校验，完整载荷哈希与云端发布标记一致。未应用到真实游戏目录。
- 68 项自动测试通过；Mac 应用重新构建。真实云端句柄和存档只在忽略目录保存，不写入源码或分发包。
