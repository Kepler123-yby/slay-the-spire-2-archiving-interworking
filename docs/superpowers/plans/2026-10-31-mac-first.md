# Mac First Save Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Mac 上实现可操作的夸克存档工具，并提供 Windows 实机验证流程。

**Architecture:** Electron 主进程负责文件事务、受限 IPC 和官方夸克 CLI 子进程。快照是带逐文件 SHA-256 的有界 JSON 容器，不依赖 ZIP 解压；云端不可变快照和完成标记隔离半成品。界面只发业务请求。

**Tech Stack:** Node.js ES modules、Electron、内置 node:test；不引入前端框架。相对于原建议 TypeScript，首轮使用直接运行的 JavaScript 降低构建环节，这是开发方选择。

**Spec:** docs/superpowers/specs/2026-10-31-sts2-quark-sync-design.md

## Global Constraints

- 本轮优先 Mac 实测；Windows 给出可执行文档，不冒充实机通过。
- 两端同 Steam 账号，内部负责夸克操作，不要求手工搬文件。
- 不覆盖真实用户存档做开发实验；上传真实数据须用户选择。
- 不记录登录凭据；首次授权由官方浏览器流程完成。
- Windows 原生官方支持仍未确认，不要求 WSL 作为默认路线。

## Review Focus

- 不可信快照路径、大小写冲突和内容损坏必须在写入前拒绝。
- 多文件更新中断后恢复旧版本，未完成事务阻止后续任务。
- 游戏运行或进度变化时禁止应用。
- 两端离线推进形成分支，禁止按时间戳自动覆盖。
- CLI 退出码为零但业务失败、列表只有预览时不能误判成功。
